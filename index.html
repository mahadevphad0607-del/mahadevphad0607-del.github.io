KISTI 발주 용역 — AI 기반 공공 R&D 가치창출 플랫폼 (SMART K2C)

2022.08 – 2024.06
데이터 엔지니어링 단독 담당

제품 시장경쟁력 평가 플랫폼의 데이터 기반을 구축한 외주 용역입니다. 일부 모델은 대학 위탁연구가 설계했고, 비전인사이드는 데이터·서빙 계층을 구축·운영했습니다.

  • 수집 아마존·다나와 Selenium 크롤러와 조달청 공공데이터포털 API 수집기를 개발했습니다. 노트북 10~20대의 분산 크롤링 팜에서 중앙 MySQL/MariaDB로 적재했습니다.
  • 범위 아마존 11,046개 중 10,985개 카테고리(ASIN 2,217,720건, 중복 제거 후 122만 건)와 다나와 2,481개 카테고리를 수집했습니다. 이후 아마존은 Rainforest API로 전환했습니다(2023 선정, 2024 구현).
  • 규모 2023년 11월 기준 8,000만 행 이상: 아마존 상품 93만·상세 1,000만·리뷰 키워드 790만, 다나와 상품 42만·리뷰 1,600만, 조달청 480만·속성 4,200만.
  • 모델 가격대별 K-means 클러스터링(Dunn index로 k 선택), KeyBERT·Sentence-Transformers·Mecab 리뷰 요구품질 키워드 추출 일 배치, NTIS 과제–NICE 기업 키워드 매칭 24만 8천 건(SQL), 조달청 가격·속성·납품 통계 SQL.
  • 서빙 FastAPI 서비스와 Jinja2·Tabulator 관리 대시보드(필터, 순차 배치 실행, 통합검색, 엑셀 다운로드)를 만들었습니다. 협력사가 개발한 KISTI 프로토타입(모델 1·2, Java/Tomcat 웹)을 사내 서버로 이전하고 Docker 실행 환경을 구성했습니다.
  • 성과 감리 산출물(운영자 매뉴얼, 초기데이터구축완료보고서)을 작성하고, KISTI 연구진 기술 회의에서 결과를 발표하며 데이터·코드 요청에 직접 대응했습니다. 3억 원 규모 본사업 계약 수주에 기여했습니다.

Python, Selenium, BeautifulSoup, pandas, SQLAlchemy, MySQL/MariaDB, scikit-learn, KeyBERT, Sentence-Transformers, FastAPI, Jinja2, Tabulator

유전체 변이 주석·위험도 리포트 시스템

2022.08 – 2023.09
단독 개발경희대 한의대 × 캐나다 바이오 연구소

개인의 유전체 데이터(VCF·칩 array)를 대규모 공개 유전체 레퍼런스와 연결해 질병·형질 리포트로 만드는 국제 협업 과제입니다. 데이터 파이프라인과 백엔드를 혼자 개발했습니다(프론트엔드는 별도 개발자).

  • 변이 호출 FASTQ → BWA → samtools → Picard → GATK → VCF. PyVCF와 정규식으로 서로 다른 입력을 정규화했습니다.
  • 레퍼런스 약 1 TB dbSNP GRCh37/38(237 GB), 1000 Genomes(770 GB), GWAS Catalog, UniProt를 염색체 단위 분할(sed/split)과 pandas 청크 적재로 MySQL에 구축하고, (chrom, pos, ref, alt) 기준 4단계 SQL 조인으로 주석했습니다.
  • 리포트 GWAS 오즈비·베타 기반 규칙형 위험점수, 1000 Genomes 26개 집단 대립유전자 빈도 비교, 질환별 의약품·한약재 정보(MedlinePlus, MeSH, ATC, PharmDB-K, OASIS)를 FastAPI JSON API로 제공했습니다. LDA·1D-CNN 질환–한약 모델은 프로토타입으로 실험했습니다.
  • 배포 Korea IDC Ubuntu 서버에 Harbor 사설 레지스트리를 직접 구축해 Docker 이미지로 배포하고, 도메인과 HTTPS(Let's Encrypt)를 설정했습니다. 외부에 공개하지 않고 내부 IP로만 접근을 허용했습니다.
  • 협업 한국–캐나다 팀 사이의 기술 가교 역할을 했고, 캐나다 연구소 디자이너와 협업했습니다.

Python, BWA, samtools, Picard, GATK, PyVCF, pandas, SQLAlchemy, MySQL, FastAPI, Docker, Harbor
